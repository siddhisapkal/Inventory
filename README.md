# 📦 Inventory Management System

An **Inventory Management System** built with **Flask**, **HTML/CSS**, and **MySQL** via **XAMPP**.  
This project enables authenticated access to manage products, stock levels, categories, and suppliers — all backed by a relational database.

> 🚀 Designed as a DBMS academic project with full-stack integration, authentication, and real-time database connectivity via XAMPP.

---

## 🔧 Tech Stack

- 🌐 **Frontend**: HTML5, CSS3
- 🧠 **Backend**: Python (Flask)
- 🗃️ **Database**: MySQL (via XAMPP)
- 🔒 **Authentication**: Flask sessions / login
- 🛠️ **Tools**: SQLAlchemy , XAMPP, phpMyAdmin

---

## 🔐 Authentication

- 👤 Login/Logout system
- 🔐 Session handling to protect admin pages

---

## 💡 Features

- ➕ Add/Edit/Delete Inventory Items
- 📦 Categorized product storage
- 🧾 Supplier details & purchase info
- 📊 Dashboard view of stock
- 🔍 Search/filter inventory
- 🔐 Admin login for access control
